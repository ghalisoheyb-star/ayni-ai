# Ayni AI — عينك الثانية

Your second mind. Your second eye.

## Vision
Ayni AI is a digital partner designed to help people think, learn, research, and work more effectively.

## Mission
Build an AI assistant adapted to Algerian users, with support for Algerian Darija and other languages.

## Core principles
- User control and permission
- Honest answers and transparent limitations
- Useful memory and personalization
- Research and critical thinking
- Continuous improvement through testing
